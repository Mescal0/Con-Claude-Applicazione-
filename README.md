# 📝 Le Mie Attività

La tua prima app, creata con Claude — **senza scrivere una riga di codice**.

**🌐 L'app è online qui: https://mescal0.github.io/Con-Claude-Applicazione-/**

## Installala sul telefono (iPhone)

1. Apri il link qui sopra con **Safari**
2. Tocca il pulsante **Condividi** (il quadrato con la freccia verso l'alto)
3. Scorri e tocca **"Aggiungi alla schermata Home"**, poi **Aggiungi**

L'icona 📝 compare nella schermata Home: si apre a schermo intero come una vera
app e funziona anche senza connessione.

È una **lista di cose da fare** (to-do list) in italiano:

- ➕ Aggiungi attività con **scadenza** (facoltativa) e **priorità** (Alta / Media / Bassa)
- ✅ Spunta le attività completate, ✏️ modificale o 🗑️ eliminale
- 🔍 Filtra: **Tutte / Da fare / Completate** — e ordina per scadenza o priorità
- ⏰ Le attività **scadute** e quelle **di oggi** sono evidenziate
- 📊 Riepilogo sempre visibile: da fare, scadute, completate
- 💾 **Salvataggio automatico**: i dati restano sul tuo dispositivo, dentro il browser
- 🌙 Tema chiaro o scuro automatico, funziona anche sul telefono

## Come si usa (nessuna installazione!)

1. Scarica il file **`index.html`** da questa pagina
   (clicca sul file → pulsante di download in alto a destra).
2. Fai **doppio clic** sul file scaricato: si apre nel tuo browser
   (Chrome, Safari, Edge, Firefox… vanno tutti bene).
3. Scrivi la tua prima attività e premi **“+ Aggiungi”**. Fatto! ✨

> 💡 Consiglio: aggiungi la pagina ai preferiti del browser, così la ritrovi al volo.

## Dove finiscono i miei dati?

Da nessuna parte su internet: restano **solo sul tuo dispositivo**, nella memoria
del browser che usi per aprire l'app. Se apri il file con un altro browser o un
altro computer, lì la lista riparte vuota.

## Vuoi cambiare qualcosa?

Non serve saper programmare: apri una sessione con Claude su questo repository e
chiedi in italiano quello che vuoi, ad esempio:

- «Aggiungi le categorie alle attività (Casa, Lavoro, Spesa…)»
- «Voglio poter scrivere una nota sotto ogni attività»
- «Cambia i colori: li vorrei sui toni del verde»

Claude modificherà l'app per te.
